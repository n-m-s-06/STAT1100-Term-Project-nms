## Things to keep in mind:

1. Try to include an explanation in comments for any complex line or 
block of code so that other people can easily read it.

2. Please sign and date your work in comments, so that it is easy to 
keep track of when things happened and make sure everyone can complete 
their required 2 updates.

3. Try to keep the group updated when you add or change things. A
single message to the chat like 'pushed a new update' should be enough.

4. If anyone isn't confident in their ability to use GitHub project 
sharing, make sure to say so. It doesn't take too long to explain in 
person, so we can set up some sort of meeting. This also applies for 
technical issues you can't resolve on your own.
